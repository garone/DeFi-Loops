# DeFi Leverage Calculator - Ultimate Edition

A comprehensive calculator for analyzing DeFi leverage strategies with multi-asset support.

## Features
- 📊 Simple & Advanced modes
- 🔧 Multi-token loop builder (cbBTC, cbETH, wstETH)
- ⚡ Real-time leverage calculations
- 📈 Scenario testing & risk analysis
- 💰 P&L comparison vs HODL strategy
- 🎯 Visual health metrics & liquidation prices

## Usage
Simply open `index.html` in your browser - no server needed!

### Manual Data Entry
1. Visit [CoinGecko](https://www.coingecko.com) for current token prices
2. Check [Aave](https://aave.com) or [Morpho](https://morpho.org) for current APY rates
3. Enter values in the token table
4. Generate loops and analyze!

## Strategy Presets
- 🛡️ Conservative (30% LTV, 3 loops)
- ⚖️ Balanced (42% LTV, 5 loops)
- ⚡ Aggressive (60% LTV, 8 loops)
